服务鉴权与在线联调配置 (Authentication)

EVA 本地 REST API 默认严格绑定在本机回环网卡（127.0.0.1）。若在设置中启用了 Token 身份校验，外部 Agent 调用及本页面在线调试时会自动携带 Authorization: Bearer <token> 请求头；若处于免 Token 模式，无需填写 Token 即可直接请求。
